# 未结事项账 [演练]

> 这里记的是对方欠我们的回复。只登记 `decisions.md` 里明确写了"对方要补什么 + 日期"的事项;我方没给对方定期限的,期限写"无"。不虚构事项。
>
> - 状态只取:待回 / 迟到 / 已回 / 沉默 / 关闭。待回和迟到合计上限 12 条,超了先关最旧的,写一行原因。
> - 新事项由 chairman 在裁决当天同步登记:编号接着表里最大的 OI 往下编,发起日写当天,期限写 YYYY-MM-DD 或"无",状态写"待回",关联条目写"<日期> · <条目标题>"。
> - 回件的结局由抽签决定,不由任何岗位决定。岗位 agent 不抽签,也不改抽签结果。

## 抽签规则 [演练·可在复盘日立条目修改]

- **谁抽**:主会话在生成来件之前运行 `python3 tools/office_tool.py draw <date>`,脚本只输出结果,不改本文件。
- **抽哪些**:状态为待回或迟到,且期限经 roll_to_workday(周六、周日顺延到周一)后不晚于当天的事项。期限为"无"的事项,每个开门日都参加抽签。断档后开门的第一天,把积压的一次抽完。
- **怎么抽**:u = int(sha256("<date>|<编号>".encode('utf-8')).hexdigest(), 16) % 20。<date> 是当天模拟日 YYYY-MM-DD,<编号> 如 OI-001。
- **结局**:u 为 0–10 按时(55%),11–14 迟到(20%),15–17 沉默(15%),18–19 坏消息(10%)。只有一条修正:期限为"无"的事项,按时区间减半,0–4 按时,5–14 迟到,15–17 沉默,18–19 坏消息。
- **怎么落账**:
  - 按时 → 当日来件最前面写一封回件,标 `[回件·OI-00x·抽签 u=N]`,内容必须和结局一致;状态改"已回"。
  - 迟到 → 回件只写"还没好";期限顺延 5 个工作日,状态改"迟到"。期限格只留新日期,旧期限写进「结局记录」。
  - 沉默 → 不写回件,只在「结局记录」记一笔;状态改"沉默"。沉默满 30 个工作日自动"关闭",写一行原因。
  - 坏消息 → 回件照写,内容是对方给的坏消息;状态改"已回",「结局记录」写明坏在哪。
  - 回件占用当日 3–5 件来件的名额。「结局记录」一律写"YYYY-MM-DD 抽签 u=N:<结局>",后续变化另起一句接在后面。
