# 浮存金账本 [演练数据]

> 浮存金 = 先收的保费 − 尚未支付的赔款。这是别人的钱,由我们持有并使用。
> **它唯一的意义在于:成本为负时,我们等于被人付钱来使用一大笔资金。**

## 定义与口径

```
浮存金成本 = 承保损失 ÷ 平均浮存金
承保损失 < 0(即承保盈利)→ 浮存金成本为负 → 这是核心竞争力
combined ratio = (赔付 + 费用) ÷ 已赚保费;>100% 即承保亏损
```
